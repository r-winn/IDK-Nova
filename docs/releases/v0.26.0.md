# Nova 0.26.0 · Real tools, a cleaner Marketplace

- Redesigned Marketplace with Plugins/Prompt packs tabs, search, installed icons and responsive catalog rows in both themes.
- Shared package icons in Marketplace and the composer; compact Install and red Remove actions, with actual download-byte progress.
- New **GitHub** plugin reads public repository information, open issues/PRs and source files, with source URLs. Read-only, anonymous and rate-limited; no private repositories or writes. Selecting it permits requests only to the public GitHub API. Local-only Work blocks this network plugin.
- New **CSV analyst** measures supplied CSV text locally, including quoted cells, row counts and numeric min/max/mean statistics. It does not upload data or act as an Excel editor.
- Prompt packs and agent tool replies now stream progressively in Responses and Chat Completions. No artificial typewriter replay after generation. Tool arguments complete before execution and the same task continues after clarification forms.
- Preserve existing installed packages, config export/import, provider credentials and the composer typing fix. Remove obsolete marketplace code from Prompt Library.

Install in Settings → Marketplace. Select an executable plugin beside chat attachments, or use its installed `@command`. Prompt packs use `@shortcuts` and remain outside the Plugins picker. A function-calling model is required; providers returning only JSON cannot offer genuine incremental streaming. Gmail/Drive OAuth connectors and arbitrary third-party packages are not implied by this catalog.

Verified with 61 frontend regressions, production compilation, local UI checks in both themes, protocol-level streaming integration tests and an actual read of Nova's public GitHub repository. Physical Windows/macOS installer testing is not claimed; download assets appear after both CI platform builds pass.

Streaming follows the [OpenAI function-calling contract](https://developers.openai.com/api/docs/guides/function-calling), and GitHub reads use its [official REST API](https://docs.github.com/en/rest/repos/repos).
