# Nova 0.22 · Clearer settings, verifiable Work

## Download

- **Windows:** choose `x64-setup.exe` for normal installation, or `.msi` for managed deployment. Install one, not both.
- **macOS:** download the universal `.dmg`, open it and move Nova to Applications. Community builds are ad-hoc signed, not Apple-notarized; see the macOS instructions in the README before opening a trusted download.
- **Existing desktop users:** check Settings → Updates after this release is published. Publication is gated on successful Windows and macOS builds.

## What changed

- Response style moved to Intelligence; memory and storage settings are consolidated. About and Updates stay at the bottom of Settings.
- Tools now offer `@tool_name` commands, Copy and Use in chat. Explicit commands run through Work permissions and must execute successfully before the model can claim completion.
- Test & diagnose shows actionable connection failures next to the model and the timestamp of the last successful test.
- File write/patch approvals show before and after. Changes made outside Nova after review are detected before writing. Recovery can undo the last recorded file operation.
- Interrupted Work retains its goal and activity. Prepare a continuation from Intelligence → Recovery, then send it to resume after checking actual project state.
- Personal Prompt library supports reusable `@shortcuts` and validated JSON import/export. Marketplace includes three bundled prompt packs.
- Local-model-only Work blocks remote model requests.
- Desktop live voice **preview** uses ephemeral tokens and WebRTC. A Realtime-compatible provider and model are required; ordinary text models do not enable voice.

## Important limits

Marketplace currently installs **text prompt packs**, not executable third-party plugins. Recovery does not restore running processes or replay uncertain external actions. Live voice does not inherit Work tools or save voice history, and physical microphone/provider end-to-end testing is still pending. Web voice requires a secure token service.

Unified search, portable ZIP bundles, global quick-window shortcuts and guided onboarding remain unfinished. This release is **not** a claim that the complete requested roadmap has shipped. See [implementation status](https://github.com/r-winn/IDK-Nova/blob/main/UPGRADE_STATUS.md).

## Validation

23 frontend regression tests and 4 native recovery/review tests passed locally. Frontend production build, macOS debug compilation and Settings UI checks passed. Installer publication additionally requires both platform jobs to pass.

Always verify important AI output. Review changes before granting access and send private data only to providers you trust.
