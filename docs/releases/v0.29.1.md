# Nova 0.29.1 · Visual consistency

- Microsoft Office application marks updated to the 2025–present icon family, with source/trademark notes.
- Workspace tab icons have a fixed 18 px slot and no oversized logo background; composer menu icons have a fixed 28 px slot.
- Installed-plugin menu uses equal-height, single-line title/subtitle rows and an independently scrollable list. Icon backgrounds follow app colors: Word blue, Excel green and PowerPoint orange.
- Office preview controls use Nova's borderless toolbar styling, grouped slide navigation and grouped zoom controls, clear tooltips and keyboard focus.
- Installation reserves progress space and button width; the installed icon collection scrolls horizontally rather than growing vertically. No content is removed or moved merely to display download progress.
- GitHub connection opens/closes a full-width animated panel. The token input and actions are separate. Instructions explain creating a fine-grained token, expiry, selected repositories and read-only permissions, with a direct GitHub settings link. Organization access may require admin approval. Nova's connector remains read-only and does not export tokens.

GitHub setup guidance follows https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens . No new account credentials were created during verification.

Verification: production build and 76 existing frontend tests passed. Browser UI verified the compact composer menu, current PowerPoint icon/tab positioning, grouped preview controls and GitHub form. A real Excel-plugin installation on the isolated test origin retained identical card bounds before and after installation. These are web UI checks; physical Windows/macOS installer verification is not claimed.
