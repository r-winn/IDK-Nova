# Nova 0.30.3 — Office reliability and Mac local settings

## Office and model context

The reported provider 400 explicitly rejected an oversized response context. This is not evidence of lost connectivity. Office inspection previously returned up to 1,000 entries/60,000 text characters in one result; completed file-generation arguments also remained in replay history.

- Inspection now returns a bounded page (default 80 entries, about 8,000 text/ID characters). Use `offset`, `limit`, `sheet` and `query`, with `nextOffset` indicating more results. Sample coverage and truncated cell text are explicitly labeled.
- XLSX overview includes sheet dimensions and actual numeric-literal statistics for the first ten numeric columns of the selected/first sheet. It does not evaluate formulas, dates or numeric-looking text and does not claim that column sums are always meaningful. Existing archive/macro limits remain enforced.
- On a context-capacity rejection, completed tool arguments/results can be shortened while preserving call/output IDs, source/filename metadata and every original user message. Server-managed chains switch to client-managed replay when necessary. Tool side effects are not rerun by this recovery. At most two context-reduction attempts are made.
- Model requests/streams can recover once from transient failures before visible text is emitted. An output-limit interruption requests smaller valid tool arguments on retry. No partial tool arguments execute. Cancellation is not retried. Partial visible final replies and generated attachments remain available on failure.
- Spreadsheet creation and Office inspection/editing use cancellable workers, keeping heavy parsing off the chat UI thread. Only relevant source attachments are sent to the worker. Vite builds module workers for web and desktop.

This is bounded client-side context management informed by [official OpenAI conversation-state guidance](https://developers.openai.com/api/docs/guides/conversation-state), not a claim that every compatible provider supports OpenAI's compaction endpoint. Original history/files remain intact. A user's request alone can still exceed a provider's context/output window; Nova cannot remove a server-imposed limit. Shorter scope or a larger-context model may still be needed. Persistent upstream outages remain explicit errors.

## Mac credentials

At the user's explicit request, Mac desktop provider keys and GitHub tokens now save in local application/browser storage without Keychain reads or writes. This is less protected than an OS vault. The UI discloses local storage. Keys held only in the previous Keychain must be re-entered once; existing Keychain entries are not erased or accessed automatically. Windows retains Credential Manager; web behavior is unchanged. Exports still exclude keys unless explicitly selected, and GitHub tokens remain excluded.

## Verification

Tests cover Office paging, real numeric totals, filtering, context overflow after completed tools, exactly-once execution during retry, and Mac local persistence without any vault call. A live browser worker test created and re-read a real 500-row XLSX, checked its numeric sum, confirmed a responsive UI heartbeat and terminated a cancelled worker.

The user's actual Excel file was not provided and its exact Goldiran failure was not replayed against their authenticated server. The reported three-minute interruption has no supplied server log; recovery tests do not establish a provider's timeout configuration or guarantee that its server will remain available.
