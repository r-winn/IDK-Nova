# Nova 0.29.0 · Designed Office outputs

## Create, organize and preview

- Microsoft Word/Excel/PowerPoint file icons identify actual DOCX/XLSX/PPTX attachments and plugin entries; trademark/source notes are in public/brands/README.md.
- Word has report, editorial and letter presets, title/subtitle hierarchy, accent dividers, legible body text, striped tables and existing header/footer/page-break tools.
- PowerPoint has minimal, midnight and editorial presets with cover, section, cards, content and quote layouts. Slides are editable PPTX objects, not screenshots or text-only outlines. Speaker notes remain separate.
- Workspace Files includes generated files and uploads from the current conversation, alongside code artifacts. Files from another chat do not leak into this list.
- Dedicated Word pages, Excel sheet tabs and PowerPoint slide navigation include zoom and existing download controls. Native Work files can also open as Office previews.

## Useful integrations, explicit activation

Select installed plugins beside the composer. An @ mention never activates an executable plugin. Prompt packs appear only in @ suggestions, not the plugin picker.

PDF research extracts actual text from a selected PDF page and reports the page count and truncation. Scanned pages require separate OCR/vision; this integration does not pretend to read image-only text. Delivery bundles creates a real ZIP of 1–20 explicitly named attachments, with no arbitrary filesystem paths.

Six new prompt packs add nine shortcuts: design_deck, design_report, lesson_plan, explain_concept, product_brief, ux_review, translate_polish, meeting_minutes and action_plan. They specify structure, evidence discipline and design constraints; they do not grant tools or guarantee model quality. Streaming remains the normal provider-dependent behavior.

## Limits and safety

Office preview is a local approximation, not Microsoft Office or a full Office editor. DOCX pagination/font substitution, inherited slide masters, images/charts/animations and merged-cell layouts can differ. Download and review important final output in Office. Spreadsheet preview displays stored values and does not execute formulas or macros. Old DOC/XLS/PPT formats, encrypted packages and macro-enabled archives are unsupported. Office files are limited to 10 MB compressed with existing expanded-archive safeguards; spreadsheet display is limited to 1,000 rows and 60 columns per sheet and slide preview to 200 slides.

Word previews run in a sandboxed, script-free frame with a restrictive content policy. External Office relationships are stripped from preview packages. Binary artifacts are not sent as model tool results; text explicitly inspected by a plugin can reach the configured provider.

ZIP inputs are restricted to actual chat attachments, 20 MB aggregate, with a 10 MB output attachment limit. Office generation is local and requires a model capable of real tool calls. File designs depend on the supplied content, selected tool arguments and available fonts; no guarantee of arbitrary publication-quality design is claimed.

## Verification

76 frontend tests and 6 native tests passed locally. Production TypeScript/Vite build passed. Tests inspect real slide colors/typography/card objects, DOCX structure, spreadsheet values/styles, external-resource stripping, actual ZIP contents, selection-only plugin activation and portable prompt-pack configuration. Browser UI checks created a new two-slide dark deck, navigated its slides, opened an actual Word page with header/table and confirmed generated attachments appear in the conversation Files panel.

Windows/macOS installers are built by release CI. Physical Microsoft Office rendering and every uploaded complex document have not been tested. Dependency audit results do not constitute a whole-application security certification.
