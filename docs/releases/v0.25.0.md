# Nova 0.25.0 · Interactive prompt workflows

- Invoke installed prompt packs with `@formal_email`, `@report_summary`, `@review_project` or `@research_brief`. Custom saved shortcuts work too; the Prompt Library's Use button inserts the shortcut.
- When details are missing, a tool-calling model can display an inline, step-by-step form in the message composer. Answer in free text or choose from suggested options; Back keeps previous answers and Next advances.
- Submitting the final step resumes the same pending model tool call, not a disconnected new conversation. Answers remain available in that chat's context; temporary side-chat answers disappear with the tab.
- Cancel releases the composer and terminates that input request. Stopping the task, changing chats or closing its temporary tab releases pending requests too.
- Plugins now shows executable installed plugins only. Prompt packs are no longer persistently selected there. Existing installed packs and configuration exports remain supported.
- Preserve the 0.24.1 typing fix; normal input does not read prompt libraries on every keystroke.

Dynamic forms depend on the provider/model supporting function calling and using the supplied tool. They do not grant permissions, send email, or justify entering passwords/API keys. Only requested details should be collected; already provided facts should not be asked again.

Verified with 54 automated frontend regressions, a production build and a local mock-provider/UI test covering four steps, Back/Next, task continuation and cancellation in the temporary side chat. No real API key or paid external model was used. Windows and macOS installers are published after both platform builds pass; physical-device testing is not claimed.

The request/answer continuation follows [OpenAI's function-calling workflow](https://developers.openai.com/api/docs/guides/function-calling). This is a Nova implementation, not a claim to reproduce ChatGPT's private internals.
