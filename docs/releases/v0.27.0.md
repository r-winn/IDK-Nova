# Nova 0.27.0 · Useful plugins, consistent settings

- Marketplace keeps the standard settings width. Its search stays visible with top spacing while scrolling; Updates uses a distinct refresh icon.
- Curated discovery: Word, Excel and GitHub. Previously installed utilities remain available without removing user configuration.
- Word creates actual downloadable DOCX documents, including Persian RTL paragraphs. Excel creates actual XLSX workbooks with multiple sheets, typed cells and styled headers. Files appear in main and temporary chat attachments; binary content is not sent back as tool results.
- Connect GitHub with a fine-grained read-only personal access token. Desktop stores the token in the existing OS credential vault; web keeps it in memory only until reload. Tokens are never included in configuration exports or model messages. Public repositories still work without a login; private access depends on the token. Only audited GET endpoints are allowed, not commits or PR creation.

Install in Settings → Marketplace, select the plugin beside attachments or invoke `@create_word_document`, `@create_excel_workbook`, or `@github_read`. A tool-calling model is required. Office plugins generate new files; they do not control installed Microsoft Office or edit existing Office documents. Existing GitHub credentials must be reconnected on another device.

Validation: actual DOCX XML inspected for Persian/RTL, XLSX reloaded for multiple sheets and cell types, credential host/method/session tests, full frontend regressions and production build. UI settings width measured unchanged at 820px; search stays fixed while scrolling. Dependency audit reports no known vulnerabilities. Real private-account and physical desktop installer tests are not claimed.

Office output uses [docx](https://docx.js.org/) and [ExcelJS](https://github.com/exceljs/exceljs). A scoped UUID dependency override fixes its known transitive advisory and is covered by actual workbook generation tests.
