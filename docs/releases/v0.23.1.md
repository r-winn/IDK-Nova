# Nova 0.23.1 · Thoughtful details, selective sharing

- Marketplace Install/Remove actions use compact, aligned icons and theme-aware hover states.
- Export config opens a section checklist. Choose appearance, providers/models, personal prompts, installed prompt packs, Intelligence, model pricing and optional personal memory. API keys are off by default and remain plaintext when explicitly included. Database credentials are never exported. Independent prompt-library import/export remains available.
- Partial imports preserve omitted destination settings. Routing/pricing travel with provider definitions so existing connections can be remapped.
- Plugin selection and outside clicks close the picker. Main and temporary chats record a snapshot of the pack names/versions sent with each request beneath the user message, even if a pack is later uninstalled.
- Deleting the last real conversation opens a fresh normal chat instead of Work. Deleting within a Work with other history still retains that Work's context.
- Intelligence sections use the shared blur transition without moving the sticky navigation. Recovery buttons have appropriate spacing. The model field uses a neutral Model name placeholder.

Prompt packs provide instructions, not executable plugins or extra permissions. Registered @tool commands continue to execute through the desktop Work tool loop, with approval and failure handling. A pack marker reports supplied instructions, not proof that a model followed them perfectly.

Local verification: 33 automated frontend regression tests, 4 native recovery tests and a production build; UI checks for marketplace buttons in light/dark themes, export choices, menu dismissal, sticky Intelligence tabs and transitions. Desktop installer publication requires both Windows and macOS CI builds to pass. See [verification limits](https://github.com/r-winn/IDK-Nova/blob/main/UPGRADE_STATUS.md).
