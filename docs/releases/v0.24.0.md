# Nova 0.24.0 · Real tools, recoverable credentials

- Preserve provider keys' saved-vault references across unavailable reads and connection edits. Explicit **Restore saved key** retries access without automatic startup dialogs or deleting Keychain entries.
- Install four executable local tools: calculator, text analysis, JSON inspector and date calculator. Select from Plugins, or invoke an installed tool with `@calculate`, `@analyze_text`, `@inspect_json` or `@date_interval`. Provider function calling is required.
- See actual execution results beneath assistant messages. Prompt-only packs are separate and clearly labelled; similar answers do not imply identical tool execution.
- Live command suggestions filter while typing and support arrow keys, Enter/Tab and Escape. Work commands remain scoped to desktop Work projects.
- Marketplace removal actions are red. Installed executable tools travel in selected configuration exports as audited, allowlisted references, not arbitrary downloaded code.
- After the last visible conversation is deleted, show a fresh normal chat even if archived history exists. Archived chats are retained.

macOS ad-hoc signatures may still require renewed Keychain authorization after an update; automatic trust continuity requires Developer ID signing. Existing keys are not removed, and physically missing keys cannot be reconstructed. Local tests cover the recovery behavior, but the reported affected-device update needs user retesting. No claim of full ChatGPT plugin ecosystem compatibility is made.

Release installers are published only after both Windows and macOS builds pass. Local checks cover 42 frontend regressions, a production build, native macOS compilation/recovery tests and mock-provider/UI smoke tests. No paid external model or real user API key was used during verification.
