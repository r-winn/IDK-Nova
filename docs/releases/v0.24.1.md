# Nova 0.24.1 · Message typing hotfix

Urgent fix for a message-composer regression introduced in 0.24.0.

- Fix dropped alternating characters while typing: command suggestions no longer restore stale text before the textarea change handler.
- Preserve Persian, English, mixed-language text, replacement input and caret editing.
- Keep live `@command` suggestions and keyboard insertion; ordinary typing no longer reads the prompt library.
- Retain all 0.24.0 tools, configuration compatibility and credential recovery behavior. No settings or chats are reset.

Verified locally with 46 automated frontend tests, a production build and browser reproduction before/after the fix. Windows and macOS installers use the same corrected frontend; physical-device retesting is still recommended. Installers are published after both platform builds pass.
