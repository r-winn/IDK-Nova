# Nova 0.23 · Simpler settings, voice and portable packs

## What's new

- Settings save automatically; Save changes and Cancel are removed. Closing flushes pending changes. Appearance edits do not rewrite unchanged credentials.
- Intelligence's sticky tab strip preserves its top spacing while the content scrolls.
- Marketplace installation shows measured byte progress. Installed packs can be removed.
- The Plugins button beside attachments selects multiple installed prompt packs; removable pills show what guides each message. Main chats and temporary side chats both support it.
- Config export includes installed pack content, saved prompts, routing/context preferences, model prices and main settings. Import preserves existing models and remaps provider routes. API keys and personal memory are opt-in; project history/files use separate Work export.
- Live voice checks the currently selected model's Realtime token endpoint and is disabled unless support is confirmed. An enabled button opens an animated in-chat voice screen with Mute, Stop and Cancel, using that same model.

## Downloads and updates

Use the Windows Setup.exe for ordinary installation, or MSI for managed deployment, not both. On macOS, open the universal DMG and move Nova to Applications. Community macOS builds are not Apple-notarized; follow the trusted-download instructions in the README. Existing desktop users can install through Settings → Updates once publication succeeds.

## Scope and verification

Marketplace packs contain instructions, not executable plugins, and grant no system permissions. Voice uses native ephemeral-token minting and WebRTC following the [official OpenAI flow](https://developers.openai.com/api/docs/guides/voice-webrtc). Audio goes to the selected provider; transcripts are temporary and Work tools are not available in voice. Web voice requires a secure token service. Token availability does not guarantee successful audio negotiation; physical microphone/live paid-provider tests remain pending.

30 frontend regression tests and 4 native recovery tests passed locally, along with the production build, Settings/Marketplace/composer UI checks, save-and-reload verification and macOS debug compilation. Production dependency audit reported no known vulnerabilities. Windows/macOS installer publication is gated on both platform CI jobs succeeding.
