# Nova 0.30.0 — Office design studio

The shared browser-side generation engine powers web, Windows and macOS. This release improves real Office files, not just instructions or marketplace labels.

## PowerPoint

- Eight palettes: minimal, midnight, editorial, executive, botanical, studio, technical and luxury. Custom colors and separate heading/body fonts are supported. Editorial/luxury and studio/technical covers have different compositions, not just different colors.
- Eleven layouts: cover, section, content, cards, quote, comparison, metrics, timeline, chart, table and image.
- Bar, line, pie and doughnut charts are editable Office chart objects with embedded workbook data. Values and labels are validated; pie charts reject negative values and empty totals.
- Two-column comparisons, 1–4 metrics, 2–5 ordered timeline steps and compact native tables use dedicated fields.
- Images use an exact PNG/JPEG chat attachment, preserving proportions. Remote images are not fetched. Missing or ambiguous image names fail explicitly.
- Dense slide text is rejected rather than silently squeezing excessive content into an unreadable layout. Speaker notes hold detail; visible source footers can hold supplied evidence references.

## Word and Excel

Word supports report, editorial, letter, proposal and academic presets, separate heading/body fonts, actual heading levels, bullet lists, callouts, optional cover pages and configurable margins. Headers/footers and page numbers remain editable. Excel supports accent/font/RTL options, frozen headers, filters, adaptive widths, banded rows and print setup. Cells remain literal values; this release does not execute spreadsheet formulas or macros.

## Prompt packs and usage

Install prompt packs in Marketplace and invoke them with `@`, for example `@executive_deck`, `@data_story`, `@brand_story`, `@client_proposal`, `@executive_report` and `@formal_email`. Select the actual PowerPoint, Word or Excel plugin beside attachments when a real file is required. Without an executable plugin, the pack can produce prose or a design specification but must not claim a file exists.

New briefs prioritize audience, purpose, evidence, coherent art direction and completed deliverables. They ask only materially necessary questions, preserve streaming and forbid invented sources or business figures. A shared quality contract also improves previously installed prompt usage without overwriting personal saved prompts. To obtain the new full text of an already-installed pack, remove and reinstall that pack; personal prompt edits are not silently replaced.

`npm run packs:sync` mechanically generates public prompt manifests from the catalog. Tests check catalog/manifest equality to prevent download-time drift. Prompt packs do not grant new permissions.

## Web availability

Work, native Work tools/recovery, local GGUF import and Chrome automation are disabled in web. Compatible Office/PDF/ZIP/GitHub plugins and prompt packs remain available. Saved configuration is not erased, unsupported plugin selections are skipped for execution, and desktop capability remains unchanged. Website and installer update workflows are unchanged.

## Verification and limits

Generation tests inspect real DOCX/XLSX/PPTX packages, chart data, embedded images, RTL, formatting, validation failures and portable pack configuration. Representative decks/documents were generated with the production engine and rendered with LibreOffice for visual inspection. This is not a claim of pixel-identical rendering in Microsoft Office. Fonts must be installed on the recipient device; Nova does not embed proprietary fonts. Provider quality and tool-calling support still affect narrative/design choices.

PowerPoint preview now displays supported charts, native tables and embedded PNG/JPEG images approximately. Complex charts, inherited masters, animations, typography and advanced Office objects can still differ; the downloadable Office file is authoritative. This is a curated design engine, not unrestricted free-form illustration or an automatic download of commercial templates.
