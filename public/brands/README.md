# Office file identity

Chrome uses Google's original mark from https://www.google.com/chrome/static/images/chrome-logo.svg to identify the Chrome integration. Google Chrome and its mark belong to Google; no affiliation is implied.

Word, Excel and PowerPoint use the 2025–present application marks, rather than the older Fabric document icons. Microsoft announced this icon family at https://techcommunity.microsoft.com/blog/microsoft365insiderblog/new-microsoft-365-icons-for-the-ai-era/4458674 . SVG copies are sourced from Wikimedia Commons, whose file pages identify Microsoft as the author and record the source and trademark status:

- https://commons.wikimedia.org/wiki/File:Microsoft_Office_Word_(2025%E2%80%93present).svg
- https://commons.wikimedia.org/wiki/File:Microsoft_Office_Excel_(2025%E2%80%93present).svg
- https://commons.wikimedia.org/wiki/File:Microsoft_Office_PowerPoint_(2025%E2%80%93present).svg

Used to identify compatible file formats, not to imply Microsoft affiliation or that Nova controls installed Office apps. Microsoft names and marks belong to Microsoft. See https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/online/branding for branding context.
